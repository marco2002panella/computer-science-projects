WASAtext Application

This project is part of a university web programming course and is based on a template provided by the professor. The template was used as a starting point to develop a full web application.

The backend has been fully implemented in Go. The API documentation is available in the doc directory and follows the OpenAPI specification. It can be opened with tools such as Swagger Editor to verify the structure and explore the available endpoints.

The frontend is currently in progress. It is being developed using the Vue framework, with a focus on responsive design and client-side interaction.
